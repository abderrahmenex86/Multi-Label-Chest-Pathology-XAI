# Reproducing the project

This note lists the exact commands for a fresh checkout, a training run, the
API, and the metric/figure scripts. It assumes a Linux shell and a CUDA-capable
GPU for training; CPU inference works with the bundled checkpoint.

## 1. Environment

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

For a reproducible CUDA environment, install the matching PyTorch wheel first
from the official selector, then install the remaining requirements.

## 2. Dataset

```bash
# Configure ~/.kaggle/kaggle.json first.
python -m src.train --download
```

Expected layout:

```text
data/
  Data_Entry_2017.csv
  images/
    00000001_000.png
    ...
```

The downloader refuses zip entries that escape `data/images/` and flattens the
`images_*/images/` folders.

## 3. Sanity check and training

```bash
python -m src.train --sanity --sanity-steps 20

python -m src.train \
  --architecture convnext_small \
  --batch 64 \
  --epochs 50 \
  --width 448 \
  --height 448
```

The default split is 70/10/10 by patient. To recreate the historical 80/20
behavior:

```bash
python -m src.train --val-fraction 0.2 --test-fraction 0.0
```

The split is deterministic from `--seed` and is written to `split.json` inside
the run directory. New runs save `test_metrics.json` after loading the best
checkpoint on the held-out test split.

For a larger ConvNeXt-Base run on a 24 GB RTX 3090:

```bash
python -m src.train \
  --architecture convnext_base \
  --width 384 --height 384 \
  --batch 32 --accumulate 2 \
  --epochs 8 --patience 3
```

The effective batch is 64. The 3090 supports bf16 natively; the pipeline falls
back to fp32 on GPUs without bf16.

## 4. Thresholds and per-class metrics

```bash
python -m src.find --run artifacts/<run>
python -m src.evaluate --run artifacts/<run> --split test
python -m src.conf_matrices --run artifacts/<run> --split test
```

`src.find` tunes thresholds on validation only. `src.evaluate` and
`src.conf_matrices` default to the test split so the operating point is not
reported on the data used to choose it.

For an older 80/20 run, `--split test` is empty; use `--split val` and label the
result as validation.

## 5. External evaluation

Training stays on NIH. External datasets are task-specific tests, not extra
14-class training data.

```bash
# Kaggle CLI; accept competition rules first.
kaggle competitions download -c siim-acr-pneumothorax-segmentation
kaggle competitions download -c rsna-pneumonia-detection-challenge
kaggle datasets download -d paultimothymooney/chest-xray-pneumonia

python -m src.evaluate_external \
  --run artifacts/<run> \
  --dataset siim \
  --data-dir data/external/siim \
  --crop-borders

python -m src.evaluate_external \
  --run artifacts/<run> \
  --dataset rsna \
  --data-dir data/external/rsna \
  --crop-borders

python -m src.evaluate_external \
  --run artifacts/<run> \
  --dataset pediatric \
  --data-dir data/external/pediatric \
  --split test
```

The SIIM and RSNA directories must contain `train-rle.csv` /
`dicom-images-train` and `stage_2_train_labels.csv` /
`stage_2_train_images`, respectively. Pediatric expects `test/NORMAL` and
`test/PNEUMONIA`.

RSNA images overlap NIH ChestX-ray14; treat it as a pneumonia/localization
check rather than an independent cohort.

## 6. API

```bash
python -m backend.main --run checkpoints/densenet121 --host 127.0.0.1 --port 8000
```

Without `--run`, the service uses the newest complete directory in `artifacts/`
and falls back to `checkpoints/densenet121`. `/health` reports whether a model
loaded.

## 7. Frontend

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

## 8. Tests

```bash
pip install -r requirements-dev.txt
python -m pytest

cd frontend
npm run lint
npm run typecheck
npm run build
```

## Known non-reproducible historical artifacts

The committed `docs/figs` and the numbers in the README come from earlier
80/20 runs. They can be inspected in `artifacts/` if that directory is present,
but they are not regenerated by the current default 70/10/10 pipeline. Rerun
training and the scripts above for current numbers.
